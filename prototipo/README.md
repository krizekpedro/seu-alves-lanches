# Protótipo navegável

Páginas estáticas para mostrar o sistema ao cliente, com dados de exemplo. Abra `index.html`.

- `painel.html`: painel de gestão (computador)
- `app-dono.html`: app do dono (celular)
- `funcionario.html`: área do funcionário com o ponto
- `cliente.html`: cardápio e acompanhamento do pedido

As páginas são geradas a partir dos arquivos de design com `node prototipo/build.mjs <pasta-dos-.dc.html>`; `runtime.js` é o pequeno motor que desenha as telas.
